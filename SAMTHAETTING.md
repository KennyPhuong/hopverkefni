# Núverandi útgáfa

Samþættingin hefur verið einfölduð 8. október 2026. Sjá LEIDBEININGAR.md
fyrir nákvæma keyrslu, forsendur og niðurstöður. Gamli samthaetting.zip
pakkinn er fyrri útgáfa; nýi pakkinn heitir einfalt_november.zip.

Flæði: lesa_novembergogn -> byggja_model -> optimize -> assignments.csv
-> óháður checker -> check.json og run.json.

main.py hefur ekkert mánaðar- eða árainntak. Gagnamappa er staðsetning
CSV-skjalanna við hlið skrárinnar. Nota skal python main.py.
